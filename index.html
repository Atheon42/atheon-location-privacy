Privacy Policy

Your browser location, your choice. Here is how Atheon Location handles location settings, local data, and optional IP-based lookups.

Publisher: Atheon  ·  Last updated: November 2, 2026

Privacy at a glance

Local-first, without analytics or advertising trackers.

Atheon Location stores your settings locally in Chrome, does not require an account, and does not sell user data. If you choose “Match Browser to IP,” the extension contacts the third-party GeoJS service to look up an approximate location for your public IP address. That provider can see the IP address making the request.

1. Purpose and scope

Atheon Location is a Chrome extension for selecting browser-reported geolocation, time zone, and locale. You can select a built-in city, enter coordinates, or align settings with the approximate location of your public IP. The optional Live Verify feature checks which settings have been applied and, when permitted, what the current tab reports.

2. Information processed and stored

  • Selected location settings: coordinates, time zone, locale, accuracy, favorites, saved presets, and extension interface preferences can be saved locally using chrome.storage.local.
  • Temporary connection and verification state: session-only data about connected tabs and whether Chrome acknowledged a location override can be stored using chrome.storage.session.
  • Current-tab verification: when you select Verify, the extension inspects time zone, regional formatting, geolocation permission, and, if the website has permission, the geolocation value reported by the current tab. These results are used locally to display status.

Atheon Location does not operate its own collection server and does not intentionally collect passwords, payment information, messages, cookies, or browsing history. It does not use analytics or advertising trackers.

3. Optional “Match Browser to IP” lookup

If you choose “Match Browser to IP” or “Refresh from IP,” the extension requests optional permission to contact GeoJS and, after you grant it, sends an HTTPS request to https://get.geojs.io/v1/ip/geo.json.

GeoJS uses the public IP address associated with that request to return an approximate location such as country, region, city, geographic coordinates, and time zone. The extension uses these values to populate its browser location settings. It does not store the public IP returned by GeoJS. The third-party service can observe the source IP address, and its own processing and retention practices are outside Atheon's control.

Using this feature does not change your public IP address, VPN, or proxy routing.

4. Chrome permissions and debugging notice

  • debugger applies browser-level overrides using the Chrome DevTools Protocol; Live Verify uses it to inspect the relevant current-tab API results. Chrome may display its standard debugging security notice while the extension is active.
  • webNavigation helps reapply selected overrides after top-level page navigation; the extension does not maintain a browsing-history database.
  • storage saves settings and short-lived session state in Chrome.
  • Optional access to https://get.geojs.io/* is requested for the user-initiated IP location feature.

Website geolocation requests remain subject to Chrome's individual site permissions. The extension does not automatically authorize location access for websites.

5. Sharing, retention, and user control

Atheon does not sell user data or transmit saved location presets or verification results to its own servers. The GeoJS request described above is the optional third-party network operation used to provide IP-based lookup. A visited website may separately receive simulated browser location values if it requests them and receives the necessary site permissions; the website's own privacy practices apply to its handling of data.

Saved extension preferences remain in Chrome's local extension storage until changed, cleared, or removed by the user. Temporary session state is cleared as Chrome's extension session data expires. Browser-level backup or synchronization controlled by Chrome is outside this extension's control.

6. Remote code and security

The extension's JavaScript, HTML, CSS, and built-in location presets are included in the installed package. GeoJS returns location data, not executable code. Atheon Location does not download or execute remote application code for this feature.

7. Changes to this policy

This policy may be updated if the extension's functionality or data practices change. Material changes will be reflected on this page with an updated revision date, and any necessary disclosures will be made through the extension and Chrome Web Store listing.
